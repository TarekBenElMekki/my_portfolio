# My Portfolio

A minimalist one-page engineering portfolio built with:

- Next.js App Router
- TypeScript
- Tailwind CSS
- Custom responsive CSS
- Lucide icons

## Main files

- `src/app/page.tsx`
- `src/app/globals.css`
- `src/data/portfolio.ts`
- `src/components/Timeline.tsx`
- `src/components/ProjectCard.tsx`

## Local commands

```powershell
npm run dev
npm run lint
npm run build
```

## Vercel

Push the repository to GitHub, import it into Vercel, and accept the
automatically detected Next.js settings.
